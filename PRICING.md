# Pricing

## gh-pr-summarize & pr-summarizer-ai

AI-powered PR summarization for GitHub. Available as both a GitHub Action and Python CLI tool.

### Free Tier
- Heuristic summary (no AI)
- Basic PR diff analysis
- Markdown output
- Available on GitHub Marketplace

### Pro Tier — $5/month
- AI-powered summaries (OpenRouter models)
- JSON + Markdown output
- Custom model selection
- Risk assessment (low/medium/high)
- Auto-comment on PRs
- Priority support

### Enterprise Tier — $500/month
- All Pro features
- Custom model training on your codebase
- Private repository support
- SSO integration
- Audit logs
- SLA support

### Individual Tier — $1/month
Just a coffee tip — supports continued development.
